# Front

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 20.0.0.

## Development server

Для запуска проект анеобходимо ввести команды: \
`cd front` \
`cd front` \
`ng serve` 

После запуска приложение доступно по адресу: `http://localhost:4200`

## Структура проекта
В папке [services](src/app/services/) можно ознакомиться с HTTP запросами, которые идут на бэк, при необходимости можно посмотреть дто
в папке [models](src/app/models/)

В файле [routes](src/app/app.routes.ts) основные маршруты веб-сайта и кому они доступны. 

`src/app/pages` содержит основные страницы приложения

- Профиль
- Главная (домашняя) страница
- Страница сотрудников
- Страница машин
- Страница клиентов
- Страница аналитики

Страницы отличаются в рендеринге в зависимости от роли пользователя
